# Правила переноса чатов

- Сохраняй исходные сообщения, порядок, даты и привязку вложений. Не добавляй в текст переписки пояснения о переносе, заглушках, недоступности файлов, пустых расшифровках или технические комментарии. Не выдумывай отсутствующий текст.
- Воспроизводи исходный вид средствами локального чата: файлы должны отображаться карточками вложений с исходными именами, изображения — изображениями. Используй наиболее близкую поддерживаемую форму, не подменяй вложения пояснительными абзацами.
- Если оригинал файла подтверждённо недоступен, утилита автоматически создаёт описание заглушки для карточки файла. Карточка остаётся в исходном сообщении; файл отсутствует и не открывается. Не создавай пустой или поддельный PDF, изображение либо подпись.
- Недоступность вложений и другие ограничения фиксируй только в исходнике, метаданных, квитанции, отчёте и выводе консоли. Не считай заглушку сохранённым оригиналом. Ошибки авторизации, временные сетевые ошибки и повреждённые данные не выдавай за отсутствие файла.
- Пустая исходная расшифровка остаётся пустой. Сохраняй связанный ответ и даты без служебной фразы вместо слов пользователя.
- Реальные файлы, предоставленные пользователем для восстановления вложений, добавляй только после его разрешения; просьба проверить заглушки не разрешает их подмену.
